# Mobile-Manufacturer-Sales-Data-Analysis-SQL-Project
Analyzed a relational database containing mobile phone sales transactions to derive business insights related to customer purchasing behavior, manufacturer performance, product sales trends, and regional sales distribution.
The project involved designing and querying a schema consisting of dimension tables (manufacturer, model, customer, and location) and a transaction fact table to solve real-world business problems using advanced SQL. Key objectives included identifying top-performing manufacturers, tracking year-over-year sales growth, evaluating customer spending patterns, analyzing transaction trends across states and zip codes, and generating actionable insights through complex joins, aggregations, ranking functions, and subqueries.
